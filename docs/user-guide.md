# Руководство пользователя

expense-tracker – консольная программа для учёта личных расходов. Расходы хранятся в текстовом файле `expenses.csv` в текущей папке.

## Установка

Нужна Java 17 или новее. Скачайте `expense-tracker-<версия>.jar` со страницы [Releases](https://github.com/PIKAniki/expense-tracker/releases) и запускайте его командой `java -jar`.

## Команды

| Команда | Что делает | Пример |
|---------|------------|--------|
| `add <дата> <сумма> <категория>` | Добавляет расход | `add 2026-09-01 350.50 food` |
| `list` | Выводит все расходы | `list` |
| `total` | Сумма всех расходов | `total` |
| `month <yyyy-MM>` | Сумма за месяц | `month 2026-09` |

Дата вводится в формате `yyyy-MM-dd`. Сумму можно писать через точку или запятую (`99.90`, `99,90`), она должна быть больше нуля.

## Пример

    java -jar expense-tracker-1.0.0.jar add 2026-09-01 350,50 food
    Added: 2026-09-01,350.50,food
    java -jar expense-tracker-1.0.0.jar add 2026-09-03 1200 transport
    Added: 2026-09-03,1200,transport
    java -jar expense-tracker-1.0.0.jar month 2026-09
    Total for 2026-09: 1550.50

## Файл с данными

По умолчанию используется `expenses.csv` в папке запуска. Другой файл можно указать свойством:

    java -Dexpenses.file=D:/money/2026.csv -jar expense-tracker-1.0.0.jar list

Первая строка файла – заголовок, дальше по одному расходу в строке: `дата,сумма,категория`.
